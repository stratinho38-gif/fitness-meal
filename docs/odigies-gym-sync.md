# Οδηγίες: Καταχώρηση κιλών/επαναλήψεων από την εφαρμογή στο Sheet

Για να γράφει η εφαρμογή στο Google Sheet, χρειάζεται ένα μικρό «script-γεφύρι» μέσα στο ίδιο το Sheet. Το στήνεις **μία φορά**, με τα παρακάτω βήματα (~5 λεπτά). Δεν χρειάζεται να καταλάβεις τον κώδικα — copy/paste είναι.

## Βήμα 1 — Άνοιξε το script του Sheet

1. Άνοιξε το Sheet «Gym program» στον browser (από τον λογαριασμό Google που είναι δικό σου το Sheet).
2. Πάνω στο μενού: **Extensions → Apps Script** (Επεκτάσεις → Apps Script). Ανοίγει νέα καρτέλα με editor κώδικα.

## Βήμα 2 — Κόλλησε τον κώδικα

1. Στον editor θα δεις ένα αρχείο `Code.gs` με λίγο κείμενο μέσα (π.χ. `function myFunction() {}`). **Σβήσε ό,τι υπάρχει**.
2. Άνοιξε το αρχείο `docs/gym-sync-apps-script.gs` από τον φάκελο του project, αντίγραψε **όλο** το περιεχόμενο και κόλλησέ το στον editor.
3. Πάτα το εικονίδιο 💾 (Save project) ή Cmd+S.

## Βήμα 3 — Deploy ως Web App

1. Πάνω δεξιά: κουμπί **Deploy → New deployment**.
2. Στο παράθυρο, πάτα το ⚙️ (γρανάζι) δίπλα στο «Select type» και διάλεξε **Web app**.
3. Συμπλήρωσε:
   - **Description**: `gym sync` (ό,τι θες)
   - **Execute as**: **Me** (εσύ)
   - **Who has access**: **Anyone** (απαραίτητο για να μπορεί να στέλνει η εφαρμογή· υπάρχει μυστικό token στον κώδικα ως προστασία)
4. Πάτα **Deploy**.
5. Θα ζητήσει άδεια: **Authorize access** → διάλεξε τον λογαριασμό σου → αν βγει «Google hasn't verified this app», πάτα **Advanced → Go to gym sync (unsafe)** → **Allow**. (Είναι δικό σου script στο δικό σου Sheet — ασφαλές.)
6. Στο τέλος θα δεις ένα **Web app URL** που μοιάζει με:
   `https://script.google.com/macros/s/AKfycb.../exec`
   Πάτα **Copy**.

## Βήμα 4 — Δώσε το URL στον Claude

Κόλλησε το URL στη συζήτηση με τον Claude. Θα το βάλει στη σταθερά `GYM_WRITE_URL` του `index.html` και θα γίνει commit. Μετά `git push` όπως πάντα.

## Πώς δουλεύει μετά

- Στη λειτουργία Γυμναστήριο, κάθε άσκηση έχει κουμπί **«Καταχώρηση»** → διαλέγεις εβδομάδα (1–12), γράφεις κιλά ή/και επαναλήψεις → **Καταχώρηση στο Sheet**.
- Η τιμή γράφεται στο Sheet στις στήλες «Εβδ N — Κιλά / Επαν.» της σωστής άσκησης και η εφαρμογή ξαναδιαβάζει το φύλλο.
- Μπορείς πάντα να διορθώνεις και χέρι μέσα στο Sheet — η εφαρμογή απλώς διαβάζει ό,τι υπάρχει εκεί.

## Αν αλλάξεις κάτι στο script αργότερα

Κάθε αλλαγή στον κώδικα του Apps Script θέλει **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** για να «πιάσει» (το URL μένει ίδιο).

## Αντιμετώπιση προβλημάτων

- **Toast «Δεν έγινε η καταχώρηση»**: έλεγξε internet· αν επιμένει, το όνομα της άσκησης στο Sheet μπορεί να άλλαξε (πρέπει να είναι ακριβώς ίδιο με ό,τι δείχνει η εφαρμογή), ή το deployment θέλει νέα version (βλ. πάνω).
- **«Δεν έχει ρυθμιστεί ακόμα η σύνδεση με το Sheet»**: το `GYM_WRITE_URL` στο index.html είναι κενό — δεν έχει γίνει το Βήμα 4.
- Από 25/11/2026 το Sheet έχει πρόγραμμα 12 εβδομάδων (στήλες «Εβδ 1…12») και η εφαρμογή καταχωρεί σε όλες.
